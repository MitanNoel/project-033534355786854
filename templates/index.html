Sistem Deteksi Emosi Teks Indonesia

Aplikasi untuk klasifikasi emosi pada teks berbahasa Indonesia menggunakan
Machine Learning dengan algoritma Naive Bayes dan SVM

Alur Kerja Sistem

1
Upload Data

Upload file CSV berisi teks dan label emosi (minimal 800 data)

2
Preprocessing

Konfigurasi preprocessing teks (lowercase, stopwords, stemming)

3
Training Model

Latih model dengan 4 skenario berbeda (NB & SVM)

4
Evaluasi Model

Bandingkan performa semua model dan pilih yang terbaik

5
Prediksi

Gunakan model terbaik untuk memprediksi emosi teks baru

Siap Memulai?

Upload file CSV Anda dan mulai proses deteksi emosi

Mulai
4 Skenario Model

Menggunakan 4 skenario berbeda dengan konfigurasi preprocessing dan feature extraction yang bervariasi

2 Algoritma

Membandingkan performa Multinomial Naive Bayes dan Support Vector Machine (SVM)

Bahasa Indonesia

Menggunakan Sastrawi untuk stemming dan stopword removal khusus bahasa Indonesia
